# Personal design profile

Use this profile only where the request, approved references, project evidence, accessibility, and the active design system leave room for judgment.

## Character

- Calm, precise, and content-first.
- Confident hierarchy with restrained decoration.
- Dense enough for real work without becoming cramped or ambiguous.
- Familiar interactions with one clear primary action per decision point.

## Preferred moves

- Establish hierarchy through type, spacing, alignment, and grouping before decoration.
- Use progressive disclosure for secondary detail and advanced controls.
- Keep page structure quiet so data, status, and user intent remain prominent.
- Make empty and error states concise, specific, and recovery-oriented.
- Use motion only to explain continuity, feedback, or spatial change.

## Avoid by default

- Decorative effects that do not serve the product.
- Containers, dividers, icons, or headings for every small group.
- Multiple competing primary actions.
- Invented metrics, generic marketing copy, or fake data that looks real.
- A custom visual language when an established project pattern already works.

Before delivery ask: does this feel like the clearest version of this product, or like a separate product imposed on it?
